MSc. Applied Statistical Modelling and Health Informatics
Research Project
King's College London

GitHub Repository for a research project investigating the difference in performances of non-/linear models and classifiers, deep learning algorithms and mixed-effects models.


Project structure

`notebooks/` - Jupyter notebooks for exploration and experiments
`src/` - reusable Python code
`data/` - raw/intermediate/processed data (not tracked by git)
`results/` - figures, metrics, tables
`configs/` - configuration files
